# 🌈 NCT DREAM 连连看 · Dream Match

一个以 **NCT DREAM** 为主题的连连看（Lianliankan / Tile-Matching）小游戏。
纯 HTML / CSS / JavaScript 实现，**零依赖、零付费素材**——成员头像全部由代码绘制的 SVG 卡通形象，音效与背景音乐由 WebAudio 实时合成，支持离线游玩（PWA）。中英双语。

> 🎮 **在线游玩：https://crysl-04.github.io/nctdream-lianliankan/**
>
> ⚠️ 非官方粉丝作品，与 SM Entertainment 无关。页面中的卡通头像为程序绘制，不含任何真实照片。

## ✨ 特性

### 玩法模式
- **经典闯关**：14 个关卡以 NCT DREAM 歌曲命名（Chewing Gum → Smoothie），难度递进，通关评星（⭐⭐⭐）
- **每关专属装扮**：成员头像随关卡歌曲换装——吹泡泡糖、戴耳机、未来墨镜、辣椒发夹、彩虹光环……卡片底色也随时代变化
- **困难模式**：设置中一键切换——时间 ×0.75、道具减半、得分 ×1.5，评星与最佳成绩独立记录
- **每日挑战**：以日期为种子生成全天固定的 8×9 棋盘，记录每日最佳、连续打卡天数，7 天打卡日历
- **无尽模式**：棋盘越滚越大，看你能坚持多少轮

### 游戏系统
- **规则纯正**：相同成员卡片、路径转折不超过 2 次即可消除（允许沿棋盘外侧绕行），死局自动洗牌且保证可解
- **道具**：💡 提示 / 🔀 洗牌 / ⏰ 加时 20 秒
- **连击**：限时连消额外加分，触发 "We Go Up!" 等欢呼语；连续消除同一成员触发 "MARK TIME!" 彩蛋
- **成就**：18 项成就（连击 / 满星 / 无尽 / 打卡 / 零道具 / 夜猫子……），解锁有音效与提示
- **战绩**：最近 12 场胜负记录；通关后可一键复制分享文本

### 体验
- **中英双语**：设置中一键切换，全界面覆盖
- **两套主题**：🌈 梦幻星河 / 🍬 粉甜糖果
- **键盘可玩**：方向键移动光标、空格/回车选中、H 提示、Esc 取消
- **合成音效 & BGM**：WebAudio 现场合成（双旋律交替 + 交互音效），可分别开关，无任何音频文件
- **手机适配**：响应式布局、安全区适配、触控优化、切后台自动暂停计时；可添加到主屏幕（PWA）离线游玩
- **进度存档**：localStorage 保存解锁进度、评星、最佳分数、成就与设置

## 🎮 玩法

1. 点击两张**相同的成员卡片**
2. 若它们可以用**不超过 2 个转折**的路径连通（路径只能经过空白处，可以绕到棋盘外面），即可消除
3. 在时间耗尽前清空整个棋盘！快速连消可以触发连击加分

## 🧩 技术要点

- **连通判定**：0-1 BFS（直行代价 0、转弯代价 1），天然给出连线坐标用于绘制动画，比"横/一折/二折"三分支写法更不易出错
- **死局保证**：每次消除后检测全局是否存在可消对，不存在则自动重排并保证重排后可解
- **每日挑战**：mulberry32 + djb2 以日期字符串为种子，同一日期全球棋盘一致
- **头像**：纯 SVG 路径绘制的卡通形象，按成员应援色 + 代表 emoji（粉丝共识：Mark🐯 Renjun🦊 Jeno🐶 Haechan☀️ Jaemin🐰 Chenle🐬 Jisung🐹）区分
- **性能**：最大棋盘（12×8=96 格）下 `findAnyPair` 实测约 0.05ms，远低于一帧预算
